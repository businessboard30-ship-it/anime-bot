Everything your anime bot needs!


STEP 1: Create Supabase Project (2 minutes)
════════════════════════════════════════════════════════════════════════════

1. Go to: https://supabase.com
2. Click "Sign Up"
3. Use GitHub (fastest)
4. Create new organization
5. Create new project
6. Choose free plan
7. Wait 1-2 minutes for project to initialize


STEP 2: Open SQL Editor (1 minute)
════════════════════════════════════════════════════════════════════════════

In your Supabase project:
  1. Left sidebar → SQL Editor
  2. New Query
  3. Paste entire supabase_migration.sql content
  4. Ready to run!


STEP 3: Execute SQL (1 minute)
════════════════════════════════════════════════════════════════════════════

1. Click "Run" button (or Ctrl+Enter)
2. Wait 10-20 seconds
3. Should show: "Query successful!"
4. See "MIGRATION COMPLETE" at bottom
5. Done!


VERIFY IT WORKED
════════════════════════════════════════════════════════════════════════════

After running SQL:

1. Go to: Table Editor (left sidebar)
2. Should see these tables:
   ✓ users
   ✓ anime_entries
   ✓ submissions
   ✓ cloned_bots
   ✓ payment_logs
   ✓ commission_tracking
   ✓ subscription_payments

If you see all 10 tables, you're READY!


GET YOUR DATABASE_URL
════════════════════════════════════════════════════════════════════════════

Now get the connection string for your .env:

1. In Supabase project:
   Settings → Database (left sidebar)

2. Scroll down to "Connection string"

3. Choose PostgreSQL

4. Copy the connection string

5. It looks like:
   postgresql://postgres:PASSWORD@db.supabase.co:5432/postgres

6. This is your DATABASE_URL!


TABLE BREAKDOWN
════════════════════════════════════════════════════════════════════════════

USERS TABLE
  - Stores user profiles
  - Bot tokens, admin status, subscriptions
  - Auto-indexed for fast lookups

ANIME_ENTRIES TABLE
  - Anime/movie database
  - Trending, latest, ongoing anime
  - Integrates with AniList + Jikan

SUBMISSIONS TABLE
  - User-submitted anime

CLONED_BOTS TABLE

BOT_ANALYTICS TABLE

ADMIN_LOGS TABLE

TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Error: "Table already exists"
  → You ran the SQL twice
  → No problem! Just means tables already created
  → Ready to use!

Error: "Permission denied"
  → Check you're using the right Supabase project
  → Should be the one you just created
  → Try again

Error: "Syntax error"
  → Make sure you copied the ENTIRE file
  → All 325 lines
  → Try copying fresh from supabase_migration.sql

Can't find connection string:
  → Settings → Database (not Settings → Account)
  → Look for "Connection string" section
  → Choose "PostgreSQL" from dropdown

THE FASTEST WAY TO GET DATABASE_URL
════════════════════════════════════════════════════════════════════════════

1. Go: https://supabase.com
2. Sign up (GitHub is fastest)
3. New Project
4. Choose free tier
5. Wait 1-2 minutes


NOW CREATE THE TABLES
════════════════════════════════════════════════════════════════════════════

1. Your project → SQL Editor
2. New Query
3. Open file: supabase_migration.sql (in your project folder)
4. Copy ALL of it
5. Paste into SQL Editor
6. Click "Run"
7. Wait 10-20 seconds
8. Done! ✓


GET YOUR DATABASE_URL (5 MINUTES TOTAL)
════════════════════════════════════════════════════════════════════════════

1. Settings (left sidebar)
2. Database
3. Scroll to "Connection string"
4. PostgreSQL tab
5. Copy the full string
6. It looks like: postgresql://postgres:PASSWORD@db.supabase.co:5432/postgres

That's your DATABASE_URL!


VERIFY TABLES CREATED
════════════════════════════════════════════════════════════════════════════

1. Table Editor (left sidebar)
2. You should see 10 tables:
   ✓ users
   ✓ anime_entries
   ✓ submissions
   ✓ cloned_bots
   ✓ payment_logs
   ✓ commission_tracking
   ✓ subscription_payments
   ✓ ai_usage_tracking
   ✓ bot_analytics
   ✓ admin_logs

🚀 STEP-BY-STEP DEPLOYMENT
═══════════════════════════════════════════════════════════════════════════

STEP 1: Gather Environment Variables (5 minutes)
────────────────────────────────────────────────

Read VARIABLES_CHECKLIST.txt and get:
  ✓ SINOBANED2_BOT_TOKEN (from @BotFather)
  ✓ ADMIN_ID (from @userinfobot)
  ✓ DATABASE_URL (from Supabase)
  ✓ GROQ_API_KEY (from console.groq.com)
  ✓ PAYSTACK keys (from paystack.com)
  ✓ STRIPE keys (from stripe.com)

Time: ~5 minutes
Status: [ ] DONE


STEP 2: Create .env File (1 minute)
────────────────────────────────────

Run:
  cp .env.example .env

Edit .env with your variables.

Time: ~1 minute
Status: [ ] DONE


STEP 3: Push Code to GitHub (5 minutes)
─────────────────────────────────────────

Your code needs to be on GitHub for Vercel to deploy it.

Run these commands:
  git init
  git add .
  git commit -m "Initial commit: Anime bot v1.1.0"
  git branch -M main
  git remote add origin https://github.com/YOUR_USERNAME/anime-bot.git
  git push -u origin main

Time: ~5 minutes
Status: [ ] DONE


STEP 4: Create Vercel Project (3 minutes)
──────────────────────────────────────────

Go to: https://vercel.com/new

1. Import GitHub repository
2. Select: YOUR_USERNAME/anime-bot
3. Click "Import"
4. Wait for build to complete

Time: ~3 minutes
Status: [ ] DONE


STEP 5: Set Environment Variables in Vercel (3 minutes)
───────────────────────────────────────────────────────

In Vercel Dashboard:

1. Go to: Settings → Environment Variables
2. Add each variable from your .env file:
   - SINOBANED2_BOT_TOKEN = xxx
   - ADMIN_ID = xxx
   - DATABASE_URL = xxx
   - GROQ_API_KEY = xxx
   - PAYSTACK_SECRET_KEY = xxx
   - PAYSTACK_PUBLIC_KEY = xxx
   - STRIPE_SECRET_KEY = xxx
   - STRIPE_PUBLIC_KEY = xxx
3. Click "Save"
4. Deploy again (Redeploy button)

Time: ~3 minutes
Status: [ ] DONE


STEP 6: Get Your Vercel URL (1 minute)
───────────────────────────────────────

Your project has a unique Vercel URL:
  https://your-project.vercel.app

Find it at: Vercel Dashboard → Project name shown at top

Your webhook URL:
  https://your-project.vercel.app/api/bot

Copy this! You'll need it next.

Time: ~1 minute
Status: [ ] DONE


STEP 7: Set Telegram Webhook (2 minutes)
──────────────────────────────────────────

Point Telegram to your Vercel bot.

Option A: Using curl (in terminal):

  curl -X POST \
    https://api.telegram.org/bot{YOUR_BOT_TOKEN}/setWebhook \
    -d url="https://your-project.vercel.app/api/bot"

Replace:
  - {YOUR_BOT_TOKEN} = Your bot token from @BotFather
  - your-project.vercel.app = Your actual Vercel URL

Option B: In browser:

  Visit this URL (replace with your values):
  https://api.telegram.org/bot1234567890:YOUR_TOKEN/setWebhook?url=https://your-project.vercel.app/api/bot

Time: ~2 minutes
Status: [ ] DONE

⚠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Bot not responding?
└─ Check Vercel logs for errors
└─ Verify TELEGRAM_WEBHOOK_URL is correct
└─ Check SINOBANED2_BOT_TOKEN is correct

Webhook error?
└─ Verify webhook URL: https://api.telegram.org/bot{TOKEN}/getWebhookInfo
└─ Should show your Vercel URL
└─ Should show "ok": true

Environment variables not working?
└─ Redeploy after adding them (automatic)
└─ Wait 30 seconds for propagation
└─ Hard refresh browser (Ctrl+Shift+R)

Database connection failed?
└─ Check DATABASE_URL is correct in both .env and Vercel
└─ Test connection: psql "YOUR_DATABASE_URL"
└─ Check Supabase project is created

AI not working?
└─ Check GROQ_API_KEY is set
└─ Verify Groq account is active at console.groq.com
└─ Try regenerating API key

🚀 QUICK START (30 MINUTES TO LIVE BOT)
═══════════════════════════════════════════════════════════════════════════

STEP 1: Get Variables (5 min)
────────────────────────────
☐ Bot Token: Open Telegram → Search @BotFather → /newbot → Copy
☐ Admin ID: Search @userinfobot → Copy ID number
☐ Database: Go supabase.com → Create project → Copy connection string
☐ Groq Key: Go console.groq.com → Create API key → Copy

STEP 2: Create .env File (1 min)
────────────────────────────────
☐ Copy: cp .env.example .env
☐ Edit: Add your 4 required variables

STEP 3: Test Locally (5 min)
────────────────────────────
☐ Run: pip install -r requirements.txt
☐ Run: python main.py
☐ Send /start in Telegram to your bot
☐ Bot responds? Good!

STEP 4: Push to GitHub (5 min)
────────────────────────────────
☐ git add . && git commit -m "Anime bot v1.1.0"
☐ git push origin main

STEP 5: Deploy to Vercel (5 min)
────────────────────────────────
☐ Go: vercel.com/new
☐ Import: Your GitHub repo
☐ Click: Import
☐ Wait for build

STEP 6: Set Environment Variables (3 min)
──────────────────────────────────────────
☐ In Vercel Dashboard → Settings → Environment Variables
☐ Add all variables from .env
☐ Click Redeploy

STEP 7: Get Webhook URL & Set (2 min)
──────────────────────────────────────
☐ Copy your Vercel URL: https://your-project.vercel.app
☐ Webhook: https://your-project.vercel.app/api/bot
☐ Run this command (replace YOUR_BOT_TOKEN & URL):

curl -X POST \
  https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook \
  -d url="https://your-project.vercel.app/api/bot"

STEP 8: Test Live (2 min)
────────────────────────
☐ Send /start to bot on Telegram
☐ Bot responds? YOU'RE LIVE! 🎉

📖 DETAILED VARIABLE EXPLANATIONS
═══════════════════════════════════════════════════════════════════════════

1. SINOBANED2_BOT_TOKEN (REQUIRED)
   What: Telegram bot authentication
   Get: @BotFather → /newbot
   Format: 1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   Time: 2 minutes

2. ADMIN_ID (REQUIRED)
   What: Your Telegram user ID
   Get: @userinfobot
   Format: 123456789
   Time: 1 minute

3. DATABASE_URL (REQUIRED)
   What: PostgreSQL database
   Get: supabase.com (recommended)
   Format: postgresql://postgres:PASSWORD@db.supabase.co:5432/postgres
   Time: 5 minutes
   Steps:
     1. Go supabase.com
     2. Sign up with GitHub
     3. Create project
     4. Settings → Database → Connection string
     5. Copy it

4. GROQ_API_KEY (REQUIRED)
   What: Free AI for recommendations
   Get: console.groq.com
   Format: gsk_abcdef123456...
   Time: 3 minutes
   Steps:
     1. Go console.groq.com
     2. Sign up
     3. API Keys → Create
     4. Copy it

5-6. PAYSTACK_SECRET_KEY & PAYSTACK_PUBLIC_KEY (OPTIONAL but recommended)
   What: Payment processor for 50 GHS bot clones
   Get: paystack.com
   Formats:
     Secret: sk_live_abcdef...
     Public: pk_live_abcdef...
   Time: 5 minutes
   Revenue: 50 GHS per clone sold
   Steps:
     1. Go paystack.com
     2. Create account
     3. Verify email
     4. Settings → API Keys
     5. Copy both

7-8. STRIPE_SECRET_KEY & STRIPE_PUBLIC_KEY (OPTIONAL)
   What: Commission tracking for clone bots
   Get: stripe.com
   Formats:
     Secret: sk_test_abcdef... (or sk_live_... for production)
     Public: pk_test_abcdef... (or pk_live_... for production)
   Time: 5 minutes
   Revenue: 10% commission on clone bot sales
   Steps:
     1. Go stripe.com
     2. Create account
     3. Developers → API Keys
     4. Copy both

9. TELEGRAM_WEBHOOK_URL
   What: Where Telegram sends messages (after Vercel deploy)
   Format: https://your-project.vercel.app/api/bot
   Get: After deploying to Vercel
   Note: Set using curl command above

10. NODE_ENV
    What: Environment type
    Set: production
    Optional: Yes (defaults to production)

11. LOG_LEVEL
    What: Logging verbosity
    Set: INFO
    Options: DEBUG, INFO, WARNING, ERROR
    Optional: Yes (defaults to INFO)

================================================================================
                        SETUP ORDER (FASTEST)
================================================================================

Follow this order - takes ~20 minutes total:

1. [ ] Get Telegram Bot Token (2 min)
   └─ Open Telegram → Search @BotFather → /newbot
   └─ Copy: SINOBANED2_BOT_TOKEN

2. [ ] Get Your Admin ID (1 min)
   └─ Open Telegram → Search @userinfobot → Send message
   └─ Copy: ADMIN_ID

3. [ ] Create Supabase Database (5 min)
   └─ Go to supabase.com → Sign up with GitHub
   └─ Create project → Copy connection string
   └─ Copy: DATABASE_URL

4. [ ] Get Groq API Key (3 min)
   └─ Go to console.groq.com → Sign up
   └─ Create API key
   └─ Copy: GROQ_API_KEY

5. [ ] (Optional) Paystack Keys (5 min)
   └─ Go to paystack.com → Create account
   └─ Get API keys
   └─ Copy: PAYSTACK_SECRET_KEY, PAYSTACK_PUBLIC_KEY

6. [ ] (Optional) Stripe Keys (5 min)
   └─ Go to stripe.com → Create account
   └─ Get API keys
   └─ Copy: STRIPE_SECRET_KEY, STRIPE_PUBLIC_KEY

7. [ ] Deploy to Vercel (10 min - see VERCEL_DEPLOYMENT.md)
   └─ Push code to GitHub
   └─ Import in Vercel
   └─ Set these env vars in Vercel dashboard
   └─ Set: TELEGRAM_WEBHOOK_URL to your Vercel URL

TOTAL TIME: ~20-30 minutes

================================================================================
                         TROUBLESHOOTING
================================================================================

Problem: "Bot not responding"
└─ Check: SINOBANED2_BOT_TOKEN is correct
└─ Check: TELEGRAM_WEBHOOK_URL is set (if using Vercel)
└─ Fix: Verify token at @BotFather

Problem: "Database connection failed"
└─ Check: DATABASE_URL is correct
└─ Check: Supabase project is created
└─ Fix: Test with: psql "YOUR_DATABASE_URL"

Problem: "AI features not working"
└─ Check: GROQ_API_KEY is set
└─ Check: Groq console shows active API
└─ Fix: Regenerate key at console.groq.com

Problem: "Payment buttons don't appear"
└─ Check: PAYSTACK keys are set
└─ Check: Paystack account is verified
└─ Fix: Use test keys first

Problem: "Vercel bot doesn't respond"
└─ Check: TELEGRAM_WEBHOOK_URL matches Vercel URL
└─ Check: All env vars in Vercel dashboard match .env
└─ Fix: Redeploy after changing env vars

Welcome! Your bot is ready. Follow these steps:

STEP 1: Setup Database (5 min)
────────────────────────────────────────────────────────────────────────────
Read: docs/setup/01_SUPABASE_SETUP.txt
Do:
  1. Go supabase.com
  2. Create project
  3. Open SQL Editor
  4. Paste: sql/supabase_migration.sql
  5. Run the SQL

Get: DATABASE_URL from Supabase Settings → Database → Connection string


STEP 2: Environment Variables (1 min)
────────────────────────────────────────────────────────────────────────────
Read: docs/setup/04_ALL_VARIABLES_EXPLAINED.txt
Do:
  1. Copy: cp .env.example .env
  2. Fill in your credentials:
     - SINOBANED2_BOT_TOKEN (from @BotFather)
     - ADMIN_ID (8933305342)
     - DATABASE_URL (from Supabase)
     - PAYSTACK_SECRET_KEY (sk_live_da548d75...)
     - PAYSTACK_PUBLIC_KEY (pk_live_43a4...)


STEP 3: Test Locally (3 min)
────────────────────────────────────────────────────────────────────────────
Run:
  pip install -r requirements.txt
  python main.py

Test:
  Open Telegram
  Send /start to your bot
  Should respond immediately!


STEP 4: Deploy to Vercel (5 min)
────────────────────────────────────────────────────────────────────────────
Read: docs/deployment/01_VERCEL_DEPLOYMENT.md
Do:
  1. git add .
  2. git commit -m "v1.1.0"
  3. git push
  4. Go vercel.com/new
  5. Import your GitHub repo
  6. Add environment variables
  7. Deploy


STEP 5: Set Webhook (2 min)
────────────────────────────────────────────────────────────────────────────
Run this command (replace YOUR_TOKEN and YOUR_VERCEL_URL):

curl -X POST \
  https://api.telegram.org/botYOUR_TOKEN/setWebhook \
  -d url="https://YOUR_VERCEL_URL.vercel.app/api/bot"


STEP 6: Test Live Bot (1 min)
────────────────────────────────────────────────────────────────────────────
1. Search your bot on Telegram
2. Send /start
3. If it responds, you're LIVE!
